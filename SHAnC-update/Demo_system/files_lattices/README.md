# files_lattices

This folder stores lattice geometry files used by test scripts and construction examples.

## Contents

- `Ag.data`, `Ag.xyz` — silver fcc lattice data in both `.data` and `.xyz` formats.
- `Au.data`, `Au.xyz` — gold fcc lattice data in both `.data` and `.xyz` formats.
- `Cu.data`, `Cu.xyz` — copper fcc lattice data in both `.data` and `.xyz` formats.
- `SiO2.data`, `SiO2.xyz` — silica fcc lattice data in both `.data` and `.xyz` formats.
- `Model_file/` — subdirectory containing the original silica input file used for nanohelix construction.

## Purpose

These lattice files are used as input sources for construction and transformation workflows inside `System_test` and the `Construction` package.

# Model_file

This folder contains the original silica lattice model used for nanohelix building.

## Contents

- `beta_quartz.data` — input lattice definition for SiO2 that is used by `System_test/Create_a_nanohelix.py`.

## Purpose

Use this file as the starting silica structure for the nanohelix construction workflow. It can be replaced with another compatible lattice input if alternative silica models are required.
